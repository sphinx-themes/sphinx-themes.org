    Immaterial Sample¶

    This is a demo site for Immaterial, generated as part of Sphinx Themes Gallery.

    Important

    This sample documentation was generated on 2026-11-16, and is rebuilt weekly.

    Quickstart¶

    1. Install this theme:

      pip install sphinx-immaterial

    2. Set the following in your existing Sphinx documentation’s conf.py file:

      html_title = "Immaterial Sample Site"
extensions.append("sphinx_immaterial")
html_theme = 'sphinx_immaterial'

    3. Build your Sphinx documentation with the new theme! [1]

    Documentation¶

    You can find this theme’s documentation at https://jbms.github.io/sphinx-immaterial/.
